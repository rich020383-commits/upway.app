Barakah Tech Hub

Equipo detrás de Upway — Plataforma de cobranza recurrente · IA aplicada a pagos · Automatización

¿Quiénes somos?

Barakah Tech Hub es un equipo de desarrollo B2B especializado en sistemas transaccionales de cobranza recurrente. Nuestro producto principal, Upway, automatiza el ciclo completo de cobro para clínicas, centros de salud, IPS y negocios en general: vencimientos, notificaciones, seguimiento de pagos y analíticas — el mismo dominio operativo que resuelve Cobrix.

Upway en números

CobranzaVencimientos automáticos, workers con colas, recordatorios programados
IAAnalíticas inteligentes, mensajería conversacional (WhatsApp, voz con Vapi)
BackendTypeScript · Node.js · PostgreSQL · procesos asíncronos
FrontendReact · Next.js · dashboards operativos

Por qué es relevante para Cobrix

  • Mismo dominio: construimos exactamente el tipo de sistema que Cobrix comercializa — cobranza recurrente, reducción de impago, notificaciones automatizadas.
  • Stack idéntico: TypeScript / Node / React / Postgres — fricción técnica casi cero.
  • IA en producción: experiencia real procesando información de pago con modelos de IA.
  • Modelo flexible: integración de productos, desarrollo conjunto, o capacidad técnica dedicada según lo que mejor convenga a Cobrix.
